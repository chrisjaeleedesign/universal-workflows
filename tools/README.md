# Universal Tools

This directory contains the **Specialist Workers** (Tier 2) of the Antigravity Workflow OS. These tools are called by the Kernel or the Hub to perform specific capabilities.

## Tool Index

| Tool | Role | Function |
| :--- | :--- | :--- |
| **[`clean.md`](clean.md)** | Janitor | Maintenance & Memory Archiving. |
| **[`archive-memory.md`](archive-memory.md)** | Memory Librarian | Targeted memory archiving. |
| **[`auto-update.md`](auto-update.md)** | Maintainer | Deep-dive directory analysis & doc sync. |
| **[`test.md`](test.md)** | QA Lead | Intelligent testing (Unit/Visual). |
| **[`smart-commit.md`](smart-commit.md)** | Release Manager | Git ops & documentation sync. |
| **[`create-workflow.md`](create-workflow.md)** | Builder | Workflow factory. |
| **[`workflow-optimize.md`](workflow-optimize.md)** | Optimizer | Self-healing process analysis. |

## Usage
These tools are generally not called directly by the user but are delegated to by the **Intake** or **Loop** workflows.
